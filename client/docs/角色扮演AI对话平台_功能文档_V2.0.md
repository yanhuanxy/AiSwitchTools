# 角色扮演 AI 对话平台｜功能文档 V2.0

- 版本：V2.0
- 状态：已开发完成（待验收）
- 日期：2026-01-29

---

## 1. 核心功能概览

### 1.1 角色管理
- **角色列表**：展示所有创建的角色，支持卡片式布局。
- **角色创建/编辑**：
  - 基础信息：名称、简介、头像上传（支持图片预览）。
  - Prompt配置：背景故事、标签、对话风格、Few-Shot示例、禁忌与边界。
  - 版本管理：支持草稿与发布状态。
- **角色详情**：展示角色完整信息及版本历史，支持从特定版本发起对话。

### 1.2 智能对话（Chat）
- **会话窗口**：
  - 实时流式响应（SSE）：打字机效果。
  - 消息气泡：区分用户与AI，支持Markdown渲染。
  - 图片展示：支持消息中包含的图片附件查看（点击预览）。
- **交互控制**：
  - 发送消息：支持文本输入与图片上传。
  - 任务控制：支持停止生成（Stop）、重试（Retry）、继续生成（Continue）。
  - 状态反馈：加载中骨架屏、错误提示与重试机制。
- **历史记录加载**：
  - 支持向下滚动查看最新消息。
  - 支持点击“加载更多历史消息”向上分页获取旧消息（Cursor分页）。

### 1.3 历史会话管理
- **会话列表**：按时间倒序展示所有历史会话。
- **会话入口**：点击进入对应的聊天页面，恢复上下文。

### 1.4 认证与账户
- **匿名访问**：默认分配匿名身份，支持基础功能试用。
- **账号绑定**：
  - 支持邮箱 Magic Link 绑定。
  - 绑定后合并数据（服务端逻辑）。
- **身份管理**：
  - 显示当前身份类型（匿名/邮箱）。
  - 支持退出登录（Logout）：清除本地凭证并重置为匿名身份。
- **Token机制**：自动刷新 Token，过期自动处理。

## 2. 技术实现与UI规范

### 2.1 UI 框架
- **Element Plus**：全面采用 Element Plus 组件库。
  - 表单：`el-form`, `el-input`, `el-upload`。
  - 布局：`el-container`, `el-card`, `el-row/col`。
  - 反馈：`el-alert`, `el-message`, `el-skeleton`, `el-empty`。
  - 导航：`el-menu`。
  - 图片：`el-image` (含 `preview-src-list`)。

### 2.2 状态管理 (Pinia)
- **Auth Store**：管理 AccessToken/RefreshToken，处理登录/登出/续期。
- **Chat Store**：管理当前会话的消息列表、流式文本缓存、生成任务状态。
- **Conversation Store**：管理会话列表及历史消息分页数据。
- **Role Store**：管理角色列表及详情数据。

### 2.3 数据交互
- **REST API**：Axios 封装，统一拦截器处理 Token 注入与错误响应。
- **SSE**：原生 EventSource 封装，支持多事件类型（meta, delta, done, error）。
- **Pagination**：基于 Cursor 的分页机制，支持双向加载（列表下拉刷新，聊天上拉加载历史）。

## 3. 差异与变更 (对比 V1.0 设计)

| 功能点 | V1.0 设计要求 | V2.0 实际实现 | 备注 |
| :--- | :--- | :--- | :--- |
| **登出逻辑** | 调用 API 后切回匿名 | 调用 API -> 清除本地 -> 获取匿名 Token | 已完善闭环 |
| **消息分页** | 自动滚动加载 | 手动点击“加载更多”按钮 | 交互更可控，避免误触 |
| **图片展示** | 附件列表 | `el-image` 嵌入消息气泡下方 | 支持大图预览 |
| **UI风格** | 自定义 CSS | 全面 Element Plus | 提升一致性与开发效率 |

## 4. 遗留与后续 (V3.0 规划)
- **移动端适配**：当前为 PC/桌面端优先布局，移动端需优化响应式。
- **高级设置**：更多模型参数调整（温度、TopP 等）。
- **多模态输入**：语音输入、文件分析等。
- **用户偏好**：主题切换（深色模式）。
