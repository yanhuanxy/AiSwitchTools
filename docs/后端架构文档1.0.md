# 角色扮演 AI 对话平台｜后端架构文档 1.0

- 版本：V1.0
- 目标：基于服务端设计文档落地可扩展框架骨架
- 范围：模块拆分、分层职责、数据模型与运行方式
- 技术栈：Node.js + NestJS + SQLite + Prisma

---

## 1. 架构分层

- Controller：协议层与路由入口，承接鉴权与请求编排
- Service：业务编排与状态流转
- Repository/DAO：数据访问与查询组合
- Provider：外部依赖抽象（模型、存储、风控、指标）

## 5. 运行方式与配置

- 全局路由前缀：`/api`
- 环境变量：
  - `DATABASE_URL`：SQLite 数据库地址
  - `PORT`：服务监听端口
- 脚本：
  - `dev`：本地开发
  - `build`：编译输出
  - `start`：运行编译产物
  - `prisma:generate`：生成 Prisma Client
  - `prisma:migrate`：执行迁移
