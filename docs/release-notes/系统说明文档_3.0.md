# 系统说明文档 3.0 (高还原度版)

## 1. 平台概述
AiSwitch Coze (V3.0) 是一个轻量化、高还原度的智能体编排平台。它不仅提供了类似 Coze/Dify 的可视化工作流编排能力，还内置了**工业级的 RAG 检索引擎**和**逻辑完备的执行运行时**。本平台旨在帮助开发者在本地环境中快速构建、调试并部署复杂的 AI Agent。

### 2.2 关键技术栈
- **后端**: NestJS + Prisma + SQLite
- **向量存储**: **LanceDB** (嵌入式、无需 Docker、高性能)
- **前端**: Vue 3 + Element Plus + @vue-flow/core
- **LLM 适配**: 支持 OpenAI / Anthropic 协议

## 3. 功能模块详解

### 3.1 真实 RAG 引擎 (Real RAG)
V3.0 彻底移除了 V2.0 的 Mock 实现，集成了 LanceDB。
- **入库流程**: 上传文件 -> 文本解析 -> 分片 (Chunking) -> 调用 Embedding API -> 存入 `data/lancedb`。
- **检索流程**: 用户 Query -> 生成 Query Vector -> LanceDB 近似最近邻搜索 (ANN) -> 返回 Top-K 文本块。
- **优势**: 真正的语义检索能力，支持持久化存储，重启不丢失。

### 3.2 增强型工作流引擎 (Advanced Workflow)
支持更复杂的业务逻辑编排。
- **节点类型**:
  - **Start**: 接收用户输入。
  - **LLM**: 调用大模型，支持变量插值 (`{{var}}`) 和系统提示词。
  - **Knowledge Base**: 动态检索知识库。
  - **Condition (新增)**: 支持 `If-Else` 逻辑分支 (包含/等于/不等于)，实现复杂的决策树。
  - **End**: 定义输出变量。
- **执行逻辑**: 基于图遍历的解释器，支持上下文变量在节点间自动传递。

### 3.3 智能体运行时 (Agent Runtime)
ChatService 实现了智能路由策略：
1.  **Workflow 优先**: 若绑定工作流，全权委托给 WorkflowEngine 执行。
2.  **RAG 兜底**: 若仅绑定知识库，自动执行检索并注入 System Prompt。
3.  **原生对话**: 纯 LLM 模式。

## 4. 接口规范与开发指南

### 4.1 核心 API
- `POST /api/chat/tasks`: 发送对话消息 (自动触发 Workflow/RAG)。
- `GET /api/workflows/:id`: 获取工作流定义。
- `PATCH /api/workflows/:id`: 保存工作流画布数据。
- `POST /api/rag/ingest`: 上传并索引文档。

### 4.2 开发环境搭建
1.  **安装依赖**: `npm install` (Root & Client & Service)。
2.  **配置环境**: 复制 `.env.example` 到 `service/.env`，配置 `OPENAI_API_KEY`。
3.  **启动服务**:
    - 后端: `cd service && npm run start:dev`
    - 前端: `cd client && npm run dev`
4.  **验证 RAG**: 确保 `service/data/lancedb` 目录有写入权限。

## 5. 性能与安全
- **性能**: LanceDB 支持十亿级向量检索，本地开发环境毫秒级响应。
- **安全**:
  - API Key 不落库，仅在内存中使用。
  - 知识库按 `knowledgeBaseId` 隔离，确保数据隐私。
